## Content Collections & MDX
I started by refactoring the [blog](/blog) and [projects](/projects) to use
Astro's [Content Collections][astro_cc]. This was a great undertaking, and it
allowed me to streamline the content management process. I did this mainly
because I wanted to leverage MDX for the ability to include components in posts.

## Homepage & Animation
A few months ago, I refactored the homepage animation to be bound to react, for
maintainability's sake. This was another great undertaking, and it allowed me to
maintain the code powering the animation much more easily, as it is all
typescript now instead of pure javascript.
